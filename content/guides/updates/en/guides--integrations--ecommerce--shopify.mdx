<p>Connect the Shopify store in Integrations, then select that store in the Shopify tool. Store connection and agent tool access are separate steps.</p><h2>Set up and test</h2><ul><li>Connect the store with the credentials/authorization requested by the integration screen.</li><li>Create a Shopify tool and select the fixed store connection. Enable the product, order and abandoned-checkout capabilities needed by the agent.</li><li>Attach the tool to the agent and test a read operation before publishing.</li><li>Use returned customer/checkout context in a separate Workflow Trigger or Contact List Call Plan when appropriate. Reading data alone does not initiate outreach.</li></ul>
