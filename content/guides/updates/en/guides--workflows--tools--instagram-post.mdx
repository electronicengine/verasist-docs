<p>The Instagram Post tool lets your AI agent publish content to a connected Instagram Business account — photos and Reels — as well as list recent posts, read comments, and reply to them, during a live conversation.</p>
<blockquote class="note">This tool acts through an Instagram account you've already connected under <strong>Channels</strong>. Connect the account first, then create the tool and point it at that account. See the <a href="/guides/integrations/channels/instagram">Instagram channel guide</a> for setup.</blockquote>
<h2>Configuration</h2>
<h3>Basic Settings</h3>
<ul>
<li><strong>Instagram Account</strong> — the connected Instagram Business account this tool publishes to</li>
<li><strong>Allow publishing</strong> — let the agent publish posts (default: on)</li>
<li><strong>Allow video posts (Reels)</strong> — let the agent publish Reels; requires publishing to be on (default: on)</li>
<li><strong>Allow reading comments</strong> — let the agent list recent posts and read their comments (default: on)</li>
<li><strong>Allow replying to comments</strong> — let the agent reply to a comment (default: on)</li>
<li><strong>Custom message</strong> — optional message played to the caller before the tool executes</li>
</ul>
<h2>How It Works</h2>
<p>The account is fixed when you configure the tool — the LLM only supplies post content at call time. Verasist uses the Meta Graph API to:</p>
<ol>
<li>Create a media container for the photo or Reel</li>
<li>Poll until the container is ready (longer budget for video)</li>
<li>Publish the container, optionally also sharing Reels to the Feed</li>
<li>Return the post permalink to the agent</li>
</ol>
<blockquote class="note">Video posts on Instagram are <strong>Reels</strong> — Meta's Graph API no longer has a separate feed-only video type. Reels can optionally also appear in the Feed via the <code>share_to_feed</code> flag.</blockquote>
<h2>Agent Usage</h2>
<h3>Publish a photo</h3>
<pre><code class="language-">publish_post(media_type="image", image_url="https://example.com/photo.jpg", caption="Big news!")
</code></pre>
<h3>Publish a Reel</h3>
<pre><code class="language-">publish_post(media_type="reels", video_url="https://example.com/reel.mp4", caption="Behind the scenes", share_to_feed=true)
</code></pre>
<p>Media can be a public HTTPS URL or a <code>attachment_uuid</code> from a previously generated/uploaded file.</p>
<h3>Read comments</h3>
<pre><code class="language-">read_comments(post_id="...")
</code></pre>
<h3>Reply to a comment</h3>
<pre><code class="language-">reply_to_comment(comment_id="...", message="Thanks for the kind words!")
</code></pre>
<p>Post and comment IDs come from prior <code>list_recent_posts</code> / <code>read_comments</code> calls.</p>
