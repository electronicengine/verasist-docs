<p>Observe an active voice run, tool events and estimated usage.</p><h2>Start monitoring</h2><ul><li>Open an ongoing voice run from the workflow run list.</li><li>Click Start live monitoring. New conversation text and tool events appear in the panel.</li><li>Stop live monitoring closes observation only; it does not hang up the call.</li></ul><h2>What is shown?</h2><ul><li>Caller/agent text, tool calls, run status, usage and estimated cost.</li><li>This feature does not provide live audio listening, microphone barge-in or human takeover.</li><li>Live transcript can be unavailable when text retention is disabled; access depends on the active organization and permissions.</li></ul><h2>Connection and results</h2><ul><li>The panel can reconnect after a disconnect. Respect missing-event or stale-update notices; do not assume missing content was observed.</li><li>Live cost is an estimate; the final amount is calculated after the conversation.</li><li>Persisted transcript, recordings and results can take time to prepare after hangup.</li></ul><p><a href="/guides/workflows/tools/call-transfer">Call Transfer settings</a> · <a href="/guides/planning/workflow-runs">Workflow runs</a></p>
