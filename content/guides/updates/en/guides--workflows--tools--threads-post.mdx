<p>The Threads Post tool lets your AI agent publish posts to a connected Threads profile — text, images, and videos — as well as list recent posts and read their replies, during a live conversation.</p>
<blockquote class="note">This tool acts through a Threads profile you've already connected under <strong>Channels</strong>. Connect the profile first, then create the tool and point it at that profile. See the <a href="/guides/integrations/channels/threads">Threads channel guide</a> for setup.</blockquote>
<h2>Configuration</h2>
<h3>Basic Settings</h3>
<ul>
<li><strong>Threads Account</strong> — the connected Threads profile this tool publishes to</li>
<li><strong>Allow publishing</strong> — let the agent publish text and image posts (default: on)</li>
<li><strong>Allow video posts</strong> — let the agent publish video posts (default: on)</li>
<li><strong>Allow reading replies</strong> — let the agent list recent posts and read their replies (default: on)</li>
<li><strong>Custom message</strong> — optional message played to the caller before the tool executes</li>
</ul>
<blockquote class="note">Threads is a Meta product, but it uses its <strong>own</strong> app and its own API host (<code>graph.threads.net</code>) — not the same Meta app as Instagram/Facebook. At least one of publishing or reading replies must be enabled.</blockquote>
<h2>How It Works</h2>
<p>The account is fixed when you configure the tool — the LLM only supplies post content at call time. Verasist uses the Threads API to create a media container, poll until it's ready, publish it, and return the post permalink.</p>
<blockquote class="note">Threads access tokens are short-lived (1 hour) but exchanged for a long-lived (~60 day) token on connect. Verasist refreshes the token when needed.</blockquote>
<h2>Agent Usage</h2>
<h3>Publish a text post</h3>
<pre><code class="language-">publish_post(media_type="text", text="Just shipped a new agent!")
</code></pre>
<h3>Publish an image or video post</h3>
<pre><code class="language-">publish_post(media_type="image", image_url="https://example.com/photo.jpg", text="Behind the scenes")
</code></pre>
<h3>Read replies</h3>
<pre><code class="language-">read_replies(thread_id="...")
</code></pre>
<p>The <code>thread_id</code> comes from a prior <code>list_recent_posts</code> call.</p>
<blockquote class="note">Function names are prefixed with your tool name — e.g. a tool named "th" exposes <code>th_publish_post</code>.</blockquote><h2>Current setup and execution</h2><p>Threads Post: configure connected threads account and allowed publishing operations, attach the saved tool to an agent, and test its operation in a workflow.</p><ul><li>Enabled operations and account access determine what the agent can do.
