<p>Page Extract (searxNcrawl): configure page-extraction tool and pre-execution message, attach the saved tool to an agent, and test its operation in a workflow.</p><h2>Configure</h2><ul><li>Tools → New tool → Page Extract (searxNcrawl)</li><li>Page-extraction tool and pre-execution message</li><li>Save, attach to the agent and test before publishing.</li></ul><h2>Behavior and limits</h2><ul><li>Enabled operations and account access determine what the agent can do. A saved connection alone does not attach the tool to an agent.</li><li>Inspect tool input, output and failures in run details. Never treat a failed operation as completed.</li><li>Service availability and usage charges depend on your hosted service configuration. If unavailable, contact your service administrator; no server environment changes are required in this customer guide.</li></ul><h2>Illustrative input and result</h2><p>The examples explain data flow, not an executable request schema.</p><pre><code class="language-json">{
  &quot;input&quot;: {
    &quot;url&quot;: &quot;https://example.invalid/hours&quot;
  },
  &quot;result&quot;: {
    &quot;markdown&quot;: &quot;# Hours\n09:00–18:00&quot;
  }
}</code></pre>
