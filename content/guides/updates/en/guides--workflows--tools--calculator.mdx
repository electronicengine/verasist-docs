<p>The Calculator tool enables your AI agent to evaluate arithmetic expressions during calls. It uses a safe AST-based evaluator that only permits basic math operations — no arbitrary code execution.</p>
<h2>How It Works</h2>
<p>The Calculator tool exposes a single <code>safe_calculator</code> function to the LLM:</p>
<ol>
<li><strong>Agent Decision</strong>: The agent encounters a math problem during conversation (e.g., pricing calculation, date math, totals)</li>
<li><strong>Expression Evaluation</strong>: The expression is parsed through Python's AST and only allowed node types (<code>+</code>, <code>-</code>, <code><em></code>, <code>/</code>, <code></em>*</code>, <code>%</code>, parentheses) are permitted</li>
<li><strong>Result Returned</strong>: The numeric result is returned to the agent, which can incorporate it into the conversation</li>
</ol>

<h2>Configuration</h2>
<p>The Calculator tool has no additional configuration — it's ready to use out of the box. Simply add it to your workflow node from the Tools panel.</p>
<h2>Agent Usage</h2>
<p>Your AI agent calls the calculator with an arithmetic expression:</p>
<pre><code class="language-">safe_calculator(expression="(150 * 3) + (75 / 5)")
</code></pre>
<p>Common scenarios:
<ul>
<li>Calculating totals, discounts, or tax during sales calls</li>
<li>Date and time arithmetic (e.g., "What date is 45 days from now?")</li>
<li>Unit conversions (e.g., square footage, currency with fixed rates)</li>
<li>Splitting bills or calculating per-person costs</li>
<li>Any math the caller asks about during the conversation</li>
</ul>
<blockquote class="note">The calculator only supports numeric arithmetic. It cannot access external APIs, databases, or execute arbitrary code. For complex calculations that depend on external data, use an <a href="/guides/workflows/tools/http-api">HTTP API</a> tool instead.</blockquote></p><h2>Current setup and execution</h2><p>Calculator: configure expression and tool access, attach the saved tool to an agent, and test its operation in a workflow.</p><ul><li>Enabled operations and account access determine what the agent can do.
