<p>Tools let agents perform configured operations. Create a tool, select its connection and permissions, save it, then attach it to the appropriate agent. Saving an integration alone does not grant an agent tool access.</p><h2>Execution and verification</h2><ul><li>Give the tool a clear purpose in its description and the agent instructions.</li><li>Choose only the operations needed by this agent. Connected external accounts and feature availability are prerequisites.</li><li>Run a test and inspect tool arguments, results and errors. Publish the tested workflow for production.</li><li>Tools such as Workflow Trigger start separate runs; Transfer to Assistant changes the conversation destination. Do not treat them as interchangeable.</li></ul><h2>Available tools</h2><ul><li><a href="/guides/workflows/tools/calculator">Calculator</a> — Expression and tool access</li><li><a
