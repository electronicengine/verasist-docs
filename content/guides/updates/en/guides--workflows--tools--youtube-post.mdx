<p>YouTube Post: configure connected youtube account and allowed publishing operations, attach the saved tool to an agent, and test its operation in a workflow.</p><h2>Configure</h2><ul><li>Tools → New tool → YouTube Post</li><li>Connected YouTube account and allowed publishing operations</li><li>Save, attach to the agent and test before publishing.</li></ul><h2>Behavior and limits</h2><ul><li>Enabled operations and account access determine what the agent can do. A saved connection alone does not attach the tool to an agent.</li><li>Inspect tool input, output and failures in run details. Never treat a failed operation as completed.</li><li>Use the connected YouTube channel to upload video, list recent uploads and read/reply to comments. Check the resulting upload status; submission is not a guarantee that processing has finished.</li></ul><h2>Illustrative input and result</h2><p>The examples explain data flow, not an executable request schema.</p><pre><code class="language-json">{
  &quot;input&quot;: {
    &quot;operation&quot;: &quot;publish&quot;,
    &quot;content&quot;: &quot;Product announcement&quot;,
    &quot;media_url&quot;: &quot;https://example.invalid/video.mp4&quot;
  },
  &quot;result&quot;: {
    &quot;status&quot;: &quot;published&quot;,
    &quot;post_id&quot;: &quot;demo-post&quot;
  }
}</code></pre>
