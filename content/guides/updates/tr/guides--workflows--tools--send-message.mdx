<p>The Send Message araç lets your AI agent send a text message to the caller (or a third party) through one of your organization's configured chat channels — WhatsApp, Telegram, or Instagram — without leaving the live conversation.</p>
<blockquote class="note">This araç sends through a channel you've already connected under <strong>Channels</strong>. Configure the channel first, then create the Send Message araç and point it at that channel.</blockquote>
<h2>How It Works</h2>
<p>The channel is fixed when you configure the araç — you pick one connected WhatsApp, Telegram, or Instagram channel. At call time, the LLM only supplies:</p>
<ol>
<li><strong>Target Identity</strong>: Who to send the message to, in the format expected by that channel</li>
<li><strong>Message</strong>: The text content to send</li>
</ol>
Verasist resolves the channel configuration for your organization, validates it, and sends the message through that channel's provider.
<h2>Configuration</h2>
<h3>Basic Settings</h3>
<ul>
<li><strong>Channel</strong>: Select one of your organization's configured chat channels (WhatsApp, Telegram, or Instagram). Only chat-capable channels appear in this list — configure one under <strong>Channels</strong> first if none are available.</li>
<li><strong>Custom Message</strong>: Optional message (text or audio) played to the caller before the araç executes</li>
</ul>
<h2>Agent Usage</h2>
<p>The LLM calls the araç with a recipient identity and message text. The expected identity format depends on the selected channel:</p>
<table>
<thead>
<tr>
<th>Channel</th>
<th>Target Identity Format</th>
</tr>
</thead>
<tbody>
<tr>
<td>WhatsApp</td>
<td>Phone number in E.164 format, e.g. <code>+14155552671</code></td>
</tr>
<tr>
<td>Telegram</td>
<td>Telegram chat ID (numeric or string)</td>
</tr>

<pre><code class="language-">send_message(target_identity="+14155552671", message="Here's the confirmation link you asked for: https://example.com/confirm")
</code></pre>
<p>Common scenarios:
<ul>
<li>Caller asks you to text them a confirmation, receipt, or summary</li>
<li>Sending a link or document reference that's easier to read than to say aloud</li>
<li>Following up with a written recap after a phone or web call</li>
</ul>
<h2>Returned Data</h2></p>
<p>After sending, the araç reports back to the agent:
<ul>
<li><strong>Status</strong>: Whether the send succeeded</li>
<li><strong>Message ID</strong>: The provider's message identifier, when available</li>
<li><strong>Channel Type</strong>: Which channel the message was sent through</li>
<li><strong>Target</strong>: The normalized recipient identity used</li>
</ul>
If the channel isn't configured, isn't found for your organization, or the provider rejects the send, the araç returns an error to the agent instead of failing the call — the conversation continues.</p>
<blockquote class="note">The araç only sends through the single channel selected at configuration time.
