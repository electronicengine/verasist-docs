## Ön koşullar

Sunucuda organizasyon API anahtarı ve yayımlanmış workflow UUID’si kullanın. Workflow’a kullanılabilir model paketi atayın; `textSessions.check()` bunu kontrol eder. Uygulama oturumları editör taslağını değil yayımlanmış tanımı kullanır. WebRTC veya mikrofon/hoparlör bağlantısı açılmaz.

TypeScript SDK’da `client.textSessions`, Python SDK’da `client.text_sessions` kullanılır. İkisi de ses bağımlılığı gerektirmeden JSON yanıtlarını ve parça parça metin akışını destekler.

## Oluşturma, yürütme, mesaj ve kapatma

Bu örnek uygulama callback’i olmadan oturum açar. Workflow’a bağlı sunucu araçları kullanılmaya devam edebilir:

<CodeGroup>
```typescript
import { randomUUID } from "node:crypto";
import { VerasistClient } from "@verasist/sdk";

const client = new VerasistClient({ baseUrl: "https://app.verasist.ai", timeoutMs: 120_000 });
const workflowUuid = process.env.WORKFLOW_UUID!;
await client.textSessions.check(workflowUuid);

// Persist this ID before sending create; reuse it only to retry this creation.
const requestId = randomUUID();
let session = await client.textSessions.create(workflowUuid, {
  request_id: requestId,
  initial_context: { locale: "en" },
  instructions: "Keep responses concise and explain tool failures clearly.",
});

try {
  session = await client.textSessions.execute(session.run_id);
  if (!session.closed) {
    session = await client.textSessions.send(
      session.run_id, "Hello, what can you help me with?", session.revision,
    );
  }
  console.log(session.turns);
} finally {
  await client.textSessions.close(session.run_id);
}
```
```python
import os
from uuid import uuid4
from verasist_sdk import VerasistClient

with VerasistClient(
    base_url="https://app.verasist.ai",
    api_key=os.environ["VERASIST_API_KEY"],
    timeout=120,
) as client:
    client.text_sessions.check(os.environ["WORKFLOW_UUID"])
    session = client.text_sessions.create(
        os.environ["WORKFLOW_UUID"], request_id=str(uuid4()),
        initial_context={"locale": "en"},
    )
    run_id = session["run_id"]
    try:
        session = client.text_sessions.execute(run_id)
        if not session["closed"]:
            session = client.text_sessions.send(run_id, "Hello", session["revision"])
        print(session["turns"])
    finally:
        client.text_sessions.close(run_id)
```
</CodeGroup>

`create()` oturum durumunu oluşturur. `execute()` ilk ajan turunu üretir veya bekleyen turu sürdürür. `send()` kullanıcı mesajını ekleyip cevabı yürütür. `get()` çalıştırmadan güncel durumu okur. `close()` oturumu bitirir. Bu metotlar tamamlanmış JSON durumunu döndürür. Yanıtı üretim bitmeden görmek için aşağıdaki streaming metotlarını kullanın.

| Yanıt alanı | Anlamı |
| --- | --- |
| `run_id` | Konuşmayı sürdürmek için saklanacak kimlik |
| `revision` | Sonraki mesajın `expected_revision` değeri |
| `status` | `pending_assistant_turn` dahil yürütme durumu |
| `closed` | Run’ın bitip bitmediği |
| `turns` | Tur ID/durumu ve kullanıcı/ajan metni |

## Yanıtı üretilirken stream olarak alın

Oturumu `create()` ile oluşturduktan sonra ilk karşılamayı TypeScript’te `executeStream`, Python’da `execute_stream` ile alın. Sonraki mesajlarda `sendStream` / `send_stream` kullanın. Mevcut `execute` ve `send` metotları tamamlanmış JSON durumunu döndürmeye devam eder.

<CodeGroup>
```typescript
import { VerasistClient } from "@verasist/sdk";

async function streamGreeting(client: VerasistClient, runId: number) {
  for await (const event of client.textSessions.executeStream(runId)) {
    if (event.event === "assistant.delta") process.stdout.write(event.data.delta);
    if (event.event === "session.completed") return event.data;
  }
}

async function streamReply(client: VerasistClient, runId: number, revision: number) {
  for await (const event of client.textSessions.sendStream(runId, "Hello", revision)) {
    if (event.event === "assistant.delta") process.stdout.write(event.data.delta);
    if (event.event === "session.completed") return event.data;
  }
}
```

```python
from verasist_sdk import VerasistClient


def stream_greeting(client: VerasistClient, run_id: int):
    for event in client.text_sessions.execute_stream(run_id):
        if event["event"] == "assistant.delta":
            print(event["data"]["delta"], end="", flush=True)
        elif event["event"] == "session.completed":
            return event["data"]


def stream_reply(client: VerasistClient, run_id: int, revision: int):
    for event in client.text_sessions.send_stream(run_id, "Hello", revision):
        if event["event"] == "assistant.delta":
            print(event["data"]["delta"], end="", flush=True)
        elif event["event"] == "session.completed":
            return event["data"]
```
</CodeGroup>

`assistant.delta` olayında `run_id`, `turn_id`, `segment_id`, `sequence` ve `delta` bulunur. Parçaları aynı segment içinde birleştirin; nihai transcript ile eşleşmek için her segmentin kenar boşluklarını temizleyip segmentleri iki satır sonuyla birleştirin. Sıra numarası tur içinde artar. Transfer sonrası karşılama ayrı `turn_id` kullanır. `session.completed` geldiğinde geçici mesajları kaydedilmiş nihai durumla uzlaştırın ve sonraki mesajda yeni `revision` değerini kullanın.

Iterator’ın kapanması veya bağlantının kopması sunucudaki üretimi iptal etmez. `get(run_id)` ile durumu okuyun; aktif üretim sırasında `status`, `pending_assistant_turn` olabilir. Aynı mesajı otomatik yeniden göndermeyin. Eşzamanlı yazma aktif tur kilidi nedeniyle 409 döndürebilir. Kaçırılan parçalar tekrar oynatılmaz; kaydedilmiş nihai sonuç okunabilir.

## Tekrar deneme ve eşzamanlılık

Oluşturma için UUID biçiminde `request_id` üretip istekten önce saklayın. Aynı organizasyon/kullanıcı için aynı ID yeniden gönderilirse mevcut oturum döner; callback kimlik bilgileri veya talimatları değiştirilmez. Yeni konuşma veya workflow için yeni ID kullanın.

Aynı oturuma yazma işlemlerini sırayla yapın. Eşzamanlı işlem, eski revision, kapalı oturum veya bekleyen tur 409 döndürebilir. Timeout, 409 veya 502 sonrasında `get(run_id)` ile durumu okuyun; istek zaten uygulanmış olabilir. `pending_assistant_turn` varsa aynı mesajı yeniden eklemek yerine `execute(run_id)` kullanın. Araç bir işlemi zaten gerçekleştirmiş olabileceği için körlemesine tekrar denemeyin.

Oturum API anahtarının organizasyonuna ve bağlı kullanıcıya aittir. Başka bir anahtar/kullanıcının aynı run’a erişebileceğini varsaymayın.

```typescript
import { VerasistClient } from "@verasist/sdk";

async function resumePending(client: VerasistClient, runId: number) {
  const current = await client.textSessions.get(runId);
  if (!current.closed && current.status === "pending_assistant_turn") {
    return client.textSessions.execute(runId);
  }
  return current;
}
```

## Uygulama araçlarını ekleme

Önce [şemaları yayımlayıp node’lara bağlayın](/developer/sdks/tools), workflow’u kaydedip yayımlayın. Oturum oluştururken aynı şemalar ve callback taşıması da verilmelidir:

```typescript
import { randomBytes, randomUUID } from "node:crypto";
import { VerasistClient, type TextTool } from "@verasist/sdk";

async function createWithTools(client: VerasistClient, workflowUuid: string,
  callbackUrl: string, registerToken: (token: string) => Promise<void>) {
  const tools: TextTool[] = [{
    name: "sdk_status", description: "Read the application's status.",
    parameters: { type: "object", properties: {}, additionalProperties: false },
  }];
  const token = randomBytes(32).toString("hex");
  await registerToken(token); // Bind to the authenticated app user before creation.
  return client.textSessions.create(workflowUuid, {
    request_id: randomUUID(),
    tool_transport: { url: callbackUrl, token, tools },
  });
}
```

`registerToken` SDK metodu değil, uygulamanızın saklama adaptörüdür. Token’ı doğrulanmış kullanıcı/tenant ve son kullanma süresiyle eşleyin; oturum bitince iptal edin.

Callback için uygulamanızın HTTPS adresini kullanın; örneğin `https://your-app.example/api/sdk/tools`. Adresin Verasist tarafından erişilebilir olması ve origin’inin izinli olması gerekir. Origin reddedilirse Verasist desteğiyle iletişime geçin. URL kullanıcı bilgisi, query veya fragment içeremez; yönlendirmeler takip edilmez.

Taşıma sınırları: 1–32 araç; `sdk_` ve ardından 1–60 harf/rakam/alt çizgi; boş olmayan ve en fazla 12.000 karakter açıklama; nesne parametre şeması; 40–256 karakter token. HTTP çağrı zaman aşımı 20 saniyedir.

## Callback karşılama

API, `Authorization: Bearer <session-token>` başlığıyla şu JSON’u gönderir:

```json
{"name":"sdk_status","arguments":{},"call_id":"tool-call-id"}
```

JSON sonuç döndürün. Non-2xx yanıtlar ile ağ/JSON hataları araç hatasına çevrilir. `dispatchTextTool` yalnızca açıkça kayıtlı handler’lara yönlendirir; HTTP isteğini doğrulamak ve kullanıcı sahipliğini denetlemek uygulamanızın görevidir.

```typescript
import { dispatchTextTool } from "@verasist/sdk";

// Call only after your HTTP layer validates the token, JSON shape and user scope.
async function handleAuthorizedCall(call: {
  name: string; arguments: Record<string, unknown>; call_id: string;
}) {
  return dispatchTextTool({
    sdk_status: async (args, callId) => {
      if (Object.keys(args).length !== 0) throw new Error("Unexpected arguments");
      return { online: true, call_id: callId };
    },
  }, call);
}
```

Yazan işlemlerde kullanıcı kapsamındaki `call_id` ile kalıcı idempotency kaydı tutun ve yinelenen çağrıya önceki sonucu döndürün. Model argümanındaki kullanıcı/tenant bilgisini, doğrulanmış token bağlamının yerine kullanmayın.


## Canlı araç durumları

`tool.started` ve `tool.completed` olayları tur sürerken gelir. İki SDK da `run_id`, `turn_id`, `tool_call_id`, `function_name` ve `status` alanlarını iletir. Durum `running`, `completed` veya `failed` olabilir; tamamlanan olayda `duration_ms` de bulunabilir. Çağrıları run, turn ve call kimliklerinin birleşimiyle takip edin; böylece eşzamanlı araçlar ayrı satırlarda görünür. Bu olaylarda araç argümanları ve sonuçları yayımlanmaz. Bağlantının kopması, çalışan bir aracın başarılı tamamlandığı anlamına gelmez.

```typescript
const tools = new Map<string, unknown>();
for await (const event of client.textSessions.sendStream(runId, "Hello", revision)) {
  if (event.event === "tool.started" || event.event === "tool.completed") {
    const call = event.data;
    const key = `${call.run_id}:${call.turn_id}:${call.tool_call_id}`;
    tools.set(key, call); // Update this call's existing UI row.
  }
  if (event.event === "assistant.delta") process.stdout.write(event.data.delta);
  if (event.event === "session.completed") session = event.data;
}
```

## HTTP üzerinden SSE

SDK iterator’ları aşağıdaki kimlik doğrulamalı POST isteklerini kullanır:

| Endpoint | Amaç |
| --- | --- |
| `/api/v1/public/agent/runs/{run_id}/execute` | İlk karşılamayı stream et veya bekleyen turu sürdür; gövde `{}` |
| `/api/v1/public/agent/runs/{run_id}/messages` | Yanıtı stream et; gövde `{"text":"Merhaba","expected_revision":1}` |

```bash
curl --no-buffer --request POST \
  "https://app.verasist.ai/api/v1/public/agent/runs/$RUN_ID/execute" \
  --header "X-API-Key: $VERASIST_API_KEY" \
  --header "Accept: text/event-stream" \
  --header "Content-Type: application/json" \
  --data '{}'
```

| Olay | İstemcinin işlemi |
| --- | --- |
| `session.started` | Oturum kimliğini ve başlangıç durumunu sakla |
| `assistant.delta` | `delta` metnini ilgili tur ve segmente ekle |
| `tool.started` | İlgili aracı çalışıyor olarak göster |
| `tool.completed` | Aracı tamamlandı veya başarısız olarak güncelle |
| `session.completed` | Kaydedilmiş nihai durum ve yeni revision ile uzlaştır |
| `session.error` | Kısmi metni tamamlanmamış say; tekrar denemeden önce durumu oku |

`Accept: text/event-stream` başlığı SSE’yi seçer; normal JSON çağrıları aynı şekilde çalışır. Yetki ve doğrulama hataları stream başlamadan HTTP hatası döner. Sonraki hatalar `session.error` ile bildirilir; SDK iterator’ları bunu `ApiError` olarak yükseltir. Bağlantı sorunları ayrıca ağ istisnası oluşturabilir. Heartbeat mesajları SSE yorumlarıdır, ajan metni değildir. Kendi ayrıştırıcınız ağ paketleri arasında bölünen olayları ve UTF-8 karakterlerini desteklemelidir. Organizasyon API anahtarını sunucuda tutun.

## Uygulama ve embed arayüzü

Text-chat test paneli, iframe/widget ve uygulama sohbetleri metin parçalarını aynı ajan balonuna ekler; eşzamanlı araç çağrılarını canlı gösterir. Sabit karşılama hazır olduğunda tek parça gelir. Modelin ürettiği ilk karşılama, yanıtlar ve transfer karşılamaları üretim parçalarıyla iletilir. Bu sözleşme yalnızca `TEXTCHAT` içindir; sesli ve speech-to-speech akışları ayrıdır.

Kendi arayüzünüzde geçici metni run ve turn kimliğine göre gruplayın; parçaları segment içinde birleştirin. Transfer karşılaması yeni bir tura aittir. Üretim sürerken ikinci mesajı engelleyin. Nihai metni yeniden eklemek yerine geçici balonları `session.completed` içindeki turlar ve attachments ile uzlaştırın. Metin veya güvenli Markdown render edin; model çıktısını ham HTML olarak eklemeyin.

Bağlantı koptuğunda sunucu mevcut turu tamamlayıp kaydeder. Mesajı otomatik tekrar göndermeden güncel durumu okuyun; kaçırılan parçalar tekrar oynatılmaz. Kısmi metni veya durumu bilinmeyen aracı tamamlandı olarak işaretlemeyin. Embed durum okuma istekleri tarayıcıda organizasyon API anahtarı yerine oturum tokenı ve izin verilen origin ile doğrulanır.

Modelin düşünmesi veya araç çağrıları ilk görünür metinden önce gerçekleşebilir. Sunucu kullanıcıya gösterilebilir metni üretildikçe iletir; cevabın tamamını bekleyip sonradan parçalara ayırmaz.

## REST ve Try it

API referansında [Text oluşturma](/api-referansi/runs/trigger-workflow), [Çalıştırma](/api-referansi/runs/text-execute), [Mesaj gönderme](/api-referansi/runs/text-message), [Durum okuma](/api-referansi/runs/text-get) ve [Kapatma](/api-referansi/runs/text-close) formlarını kullanın. Try it JSON yanıtını, SDK streaming `Accept: text/event-stream` başlığını kullanır. Oluşturmada workflow UUID ve UUID biçiminde `request_id`; mesajda güncel `expected_revision` gereklidir. Sesli ve görüntülü kullanım için [run akışını](/developer/sdks/live-voice-session) kullanın.


Başlatma artık ortak run endpointinde `run_type: "voice" | "video" | "text"` ile yapılır. Alan verilmezse mevcut telefon/kanal davranışı korunur. Text için UUID `request_id` gerekir; mesajlar ve kapatma `/api/v1/public/agent/runs/{run_id}` altında çalışır. Eski oturum adresleri yalnızca uyumluluk alias’ıdır.
